## 3. Где мы (незакрытый вопрос)

После записи зеркала и seccfg телефон **не предъявил Android-композит
`22d9:2046`**. Наблюдения:

- `test11` (запись) → скрипт отправил reboot;
- далее в dmesg только `22d9:0006` (preloader), цикл ~110 с;
- в 22:00 (после hard reset Vol+ + Power) — на USB **вообще ничего**
  (`test13` пуст, `usb_watch.log` без событий);
- вибрация при Vol+ + Power — это аппаратный сброс PMIC, к загрузке отношения
  не имеет.

Рабочие гипотезы, в порядке вероятности:

1. **Телефон просто выключен/в режиме зарядки** (`para` ENV содержит
   `off-mode-charge=1`): preloader от кабеля даёт `0006` и ждёт, а после
   отключения кабеля USB не появляется вовсе. Лечится нажатием Power.
2. **LK выключает телефон** в общем power-off блоке (`0x500557C0`) — например,
   AVB/boot-state «red» при разлоченном состоянии. Тогда в логе будет
   `0006` → `<none>` через 1–3 с.
3. **t-base SFSRP** упал в `Mismatch between the counters` после записи RPMB
   (сдвиг аппаратного счётчика) → TEE/FBE проблемы → загрузка не доходит до
   Android USB. Смягчение: откат зеркала тем же ключом.

Побочно: ранний тест `para` стёр запись `dm_ota=1` из ENV (осталось
`off-mode-charge=1`) — безвредно.

## 4. Как проверить и как откатиться

### Проверка загрузки
```bash
/home/musin/watch_usb.sh          # 10 минут, пишет /home/musin/usb_watch.log
# нажать Power 3 с (без Vol+), подождать 90 с
# если пусто: Vol+ + Power 15 с, отпустить, 10 с, Power 3 с
```

Расшифровка: `0006 → 2046` = Android; `18d1:…` = fastboot;
`0006 → <none>` = LK выключил; `0006` висит = preloader ждёт DA.

### Состояние (read-only)
```bash
./run_unlock_state_check.sh       # seccfg + зеркало + вердикт
```
Устройство должно быть в preloader (`22d9:0006`).

### Откат в сток (если Android не поднимается)
```bash
MIRROR_RESTORE=1 ./run_rpmb_unlock_mirror.sh      # зеркало -> locked=1
# затем вернуть seccfg из /home/musin/seccfg_before_mirror_unlock_20261024_214627.bin
```
Проверено ранее: именно это состояние (`lock=4` + `mirror=1`) грузило Android.

## 5. Что дальше

1. **Определить, что происходит при включении** (п.4): Android / fastboot /
   power-off / preloader-hang.
2. Если **Android** поднялся: `adb devices`; если ADB нет — теперь загрузчик
   разлочен, и можно через DA прошить `boot_a`, пропатченный под `adbd`
   (добавить `ro.adb.secure=0` / `service.adb.tcp.port=5555`), с полным
   бэкапом `boot_a` + `vbmeta_a`; проверить, ослабляет ли `lock=3` AVB.
3. Если **fastboot** доступен: `fastboot devices`, `fastboot getvar unlocked`,
   `fastboot oem device-info` — и дальше патченный boot/рекавери.
4. Если **LK выключается**: откатить сток, затем эксперимент с
   `reset-reason class` (путь (b) в fastboot) и/или с `dm_verity`/`sboot`
   в записи seccfg.
5. Если **preloader-hang**: снять `expdb`/`misc` (уже умеем) и проверить
   BCAB/BCB; возможно, дело в счётчике RPMB — тогда откат зеркала.
